# Dashboard — What's On My Plate

> The owner's plate as a dated index. **At every session start,** before the task, raise (don't run) each line dated today or earlier, overdue first, one line each.
> Each line is a pointer: its context lives in the linked note, never here. **Line:** `- YYYY-MM-DD · what → [[note]] §section`, one line, sorted by date. **The date is when to raise it:** a deadline minus prep and buffer · a check or own plan: its day · waiting on someone: expected reply + a few days.
> **Priorities:** ranked, each → its owning note; only the owner reorders them (Reflect reviews them).
> **Recurring:** the date is the next check-in; the interval sits in the text.
> **Upkeep, in the same turn:** any decision to do or check something later gets a dated line (a date, never "until X happens") · an outcome → delete the line (one-off) or roll it forward (recurring) · deferred → re-date · a changed operational note → rewrite its line, never append. Budget: 50 lines.
